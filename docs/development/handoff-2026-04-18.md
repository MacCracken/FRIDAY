## Recommended next cuts

1. **Tag 0.5.0**. Everything above is ready.
2. After tag, delete `packages/core/src/` and slim `packages/core/package.json` (or remove the workspace entry entirely).
3. Then tackle `--features edge` feature-gating as a size follow-up, or start on the Cyrius port pathway when `cyrius-ts` is ready.

## Trajectory note

Cyrius port is deferred until `cyrius-ts` is ready. The user is currently bringing Cyrius up on Apple Silicon (morning of 2026-04-18) and then Windows. When Cyrius reaches Rust feature parity, the plan is a single clean port — dashboard and backend together, no TS ↔ Rust ↔ Cyrius shim. Until then, **this Rust stack is the shipping target**, not a throwaway.
